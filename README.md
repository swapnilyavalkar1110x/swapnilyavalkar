<h1 align="center">🏆 Featured Projects</h1>

Here are some **key projects** I've designed and built, spanning **Agentic AI** and **AWS/Azure cloud infrastructure**:

1. **Project Sovereign — Autonomous Self-Healing Infrastructure**  
   *Designed and built a 7-layer autonomous self-healing cloud infrastructure platform as AI/ML Architect: OpenTelemetry + Apache Flink ingestion → Neo4j causal service graph → Qdrant semantic incident memory → Groq LLM + RAG root cause analysis → risk-tiered HITL dashboard → Kubernetes Operator remediation → River ML continuous learning. Achieved sub-60-second anomaly detection and MTTR reduced from 40+ minutes to under 2 minutes.*  
   **Technologies**: River ML, Qdrant, Sentence Transformers, Groq API, LangChain RAG, SHAP, Neo4j, Kubernetes, OpenTelemetry, Apache Flink, Python.

2. **AirgapX — Offline AI Security Copilot**  
   *Designed and built a fully functional offline AI security copilot for air-gapped endpoints: Go telemetry agent (gopsutil) → Python LangGraph 3-agent pipeline (Collector → Correlator → Triage) → local Ollama LLM → FastAPI REST server → React/Vite dashboard, with MITRE ATT&CK classification and SHAP explainability.*  
   **Technologies**: Go, LangGraph, Ollama, FastAPI, React, Vite, SHAP, MITRE ATT&CK, SQLite, Python.

3. **SRE Runbook RAG Assistant, Incident Triage & IaC Validator Agents**  
   *Delivered production agentic AI systems for SRE operations: a Corrective-RAG runbook assistant (LangChain + ChromaDB), a LangGraph ReAct-based incident triage agent with LangSmith tracing, an IaC validator agent with human-in-the-loop approval (Checkov + OPA), and a 4-agent CrewAI SRE Operations Crew (monitoring → diagnostics → remediation → report).*  
   **Technologies**: LangChain, LangGraph, LangSmith, CrewAI, ChromaDB, FastAPI, Pydantic, Checkov, OPA, AWS Lambda, DynamoDB.

4. **Zero-Downtime AWS Infrastructure for an AI-Powered Clinical Coding Service**  
   *Architected and delivered full AWS infrastructure (ECS Fargate, private API Gateway, Lambda, OpenSearch with 2.77M documents, ElastiCache Redis, RDS MySQL, SQS+DLQ, KMS) and migrated it from an isolated VPC to a shared enterprise VPC with Azure VPN transit integration, with zero downtime — achieving 65.92% coding accuracy against a 65% SoW target.*  
   **Technologies**: AWS ECS Fargate, API Gateway, Lambda, OpenSearch, ElastiCache, RDS, SQS, KMS, Azure VPN.

5. **Engineering Metrics Platform (Serverless)**  
   *Built a fully serverless platform ingesting GitHub API data (commits, issues, releases, traffic) across an entire engineering organization via Lambda + Step Functions + DynamoDB + API Gateway, replacing a manual QBR spreadsheet process with live Grafana Infinity dashboards.*  
   **Technologies**: AWS Lambda, Step Functions, DynamoDB, API Gateway, S3, Python, Boto3, Grafana Infinity.

6. **License Cost Optimization — $1.14M Annual Savings**  
   *Automated Tableau/software license usage tracking with Python + REST API to detect and deactivate inactive accounts, saving $1.14 million per year and earning leadership recognition.*  
   **Technologies**: Python, REST APIs.
